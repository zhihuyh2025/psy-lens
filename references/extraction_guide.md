# 六维心理基组提取指南

## 维度一：可交互性（s1 / o1）

| 分量 | 含义 |
|------|------|
| s1 | 主体对自身能力的主观评估 |
| o1 | 主体对现实条件的客观判断 |

s1高："我能""我有信心""有办法" | s1低："我不行""做不到""没希望"
o1高："条件成熟""资源到位" | o1低："条件不足""现实不允许"

## 维度二：社会规范（s2 / o2）

| 分量 | 含义 |
|------|------|
| s2 | 主体认为外界如何看待自己 |
| o2 | 外界实际如何看待（引述的反馈） |

s2高："大家支持""他们理解" | s2低："他们反对""没人理解"
o2高：引述具体正面反馈 | o2低：引述具体反对意见

## 维度三：表达意愿（s3 / o3）

| 分量 | 含义 |
|------|------|
| s3 | 主体有多想说 |
| o3 | 环境是否让说 |

s3高："我想说""憋不住""必须说" | s3低："说不出口""不想说"
o3高："环境允许""可以随便说" | o3低："不让说""不方便说"

## 跨维度校验

- s3低+o3高=主动自我抑制
- s1高+o1极低=只有文本明确写盲目乐观时才合理
- 无明显线索时取0.5

## 置信度标注

h=直接证据 m=间接线索 l=默认值
置信度l的维度下游权重降低。
